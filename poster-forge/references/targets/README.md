# targets

โฟลเดอร์นี้เก็บภาพเป้าหมาย (target) ที่ใช้เทียบสไตล์ ใน repo มีเฉพาะภาพที่เจ้าของอนุมัติแล้ว (`approved-*.jpg`)

ภาพอ้างอิงที่ผู้ใช้ส่งมา (`userref-*`, `ref-face-*`, `ref-gun-*`) และเป้าหมายที่สร้างจากภาพเหล่านั้น (`face-target.jpg`, `gun-target.jpg`) ไม่ได้อยู่ใน repo เพราะเป็นงานของบุคคลอื่นหรือมีบุคคลอยู่ในภาพ ให้ใส่ภาพของคุณเองด้วยชื่อเดียวกันเมื่อใช้งานจริง
