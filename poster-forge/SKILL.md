# Poster Forge

ประกอบโปสเตอร์ PNG จากรูปที่มีอยู่หรือรูปที่เจนด้วย Gemini ผ่าน `scripts/generate.ps1` ด้วย HTML/Canvas แล้วเรนเดอร์ผ่าน Chrome แบบ headless บนการ์ดจอเท่านั้น เครื่องนี้ไม่มี Python, Node หรือ ImageMagick จึงใช้ PowerShell กับ Chrome

**ขอบเขต:** ทำเฉพาะโปสเตอร์ Support จตุรัสสองสไตล์ใน `references/support-styles.md` เท่านั้น ถ้าผู้ใช้ขอแบบอื่น (gacha, ranking, มาสคอต, แบนเนอร์) ให้บอกว่าเกินขอบเขต skill นี้ และถามว่าจะทำเป็นสไตล์ A หรือ B แทน
**สิ่งที่ทำได้:** เจนตัวละครกรีนสกรีน เกรดสี แสงขอบ เอฟเฟกต์ ตัวหนังสือ การ์ดไอเทม ฟุตเตอร์
**ข้อจำกัด:** Claude วาดภาพเองไม่ได้ การเจนทุกครั้งเรียก API แบบเสียเงินและต้องมี `GEMINI_API_KEY` ถ้าไม่มีคีย์ให้ดูหัวข้อ "เจนภาพด้วย AI"

## ขั้นตอน

1. **รับโจทย์:** ต้องรู้หัวข้อ รูปหลัก รายการของรางวัลและจำนวน (ถ้ามี) ชื่อเซิร์ฟเวอร์และช่องทางติดต่อ ขนาดภาพ ถามเฉพาะที่ขาด ข้อความที่เป็นข้อเท็จจริง เช่น ราคา จำนวน วันที่ ลิงก์ ต้องมาจากผู้ใช้เท่านั้น
2. **ตั้งโฟลเดอร์งาน:** `<workdir>\posters\<ชื่องาน>\` คัดลอกรูปเข้าโฟลเดอร์นี้ อย่าแก้ไฟล์ต้นฉบับ
3. **เปิดดูรูปทุกรูป** เพื่อเลือกท่าทาง ทิศหน้า และสีที่เข้ากัน
4. **เจนรูปที่ขาด:** ถ้าไม่มีรูปหลัก หรือรูปไม่มีพลังพอ ให้ทำตามหัวข้อ "เจนภาพด้วย AI"
5. **เตรียม cut-out:** ถ้ารูปยังมีพื้นหลัง ใช้ `cutout.ps1` แล้วเปิดไฟล์ `.check.jpg` ทุกครั้ง สีบานเย็นในตัวละครคือรู ให้ลด `-Tolerance` พื้นหลังรกเกินไปให้ขอ PNG โปร่งใสจากผู้ใช้ หรือใช้ออปชัน `fade` กลืนขอบ
6. **เลือกสไตล์:** อ่าน `references/support-styles.md` แล้วเลือก A (หน้าใหญ่) หรือ B (ยื่นปืน) เปิดดูภาพเป้าหมายใน `references/targets/` ก่อนทุกครั้ง ถ้าผู้ใช้ไม่ระบุ ให้ใช้ A กับระดับทั่วไปและ B กับ Gang เลือกสีจากโลโก้หรือชุดตัวละคร
6.5. **ทำตามรูปตัวอย่างที่ผู้ใช้ยืนยัน** (`references/support-styles.md` หัวข้อ "แนวที่ผู้ใช้ยืนยัน"): เจนพื้นหลัง X-slab ต่อระดับ (`agy-gen.ps1`) เจนตัวละครแบบ medium close-up จากรูปของผู้ใช้ ตัดพื้นเขียว ครอปแนวนอน `upscale.ps1` แล้วตัวละครเต็มภาพถึงขอบล่าง การ์ดโปร่งบนแผงมืดโปร่งกลางล่าง `grainTop` ผู้ใช้ติเรื่อง "แถบสีดำด้านล่าง เสื้อตัวละครขาด การ์ดทึบ วงคลื่น" มาแล้ว
7. **เขียนสเปก:** หนึ่งระดับ = หนึ่งแผ่น เริ่มจาก `templates/support-face.json` (A ไม่เกิน 15 ชิ้น), `templates/support-dense.json` (A 16-28 ชิ้น `cols 7 aspect .58`) หรือ `templates/support-gun.json` (B) บันทึกเป็น `poster.json` ในโฟลเดอร์งาน ตัวละครต้องเป็นหน้า FiveM (ลำดับแหล่งตัวละครและสคริปต์ `isolate.ps1` / `erase-white.ps1` อยู่ใน `references/support-styles.md`) ฟิลด์ทั้งหมดอยู่ใน `references/spec.md`
8. **เรนเดอร์:** `scripts/render.ps1 -Spec <poster.json>`
9. **ตรวจด้วยตา:** เปิด PNG ดูจริง ไล่ตาม "เช็กลิสต์" แล้วแก้สเปกและเรนเดอร์ซ้ำจนผ่าน อย่าส่งงานจากรอบแรกโดยไม่ได้ดู
10. **ส่งงาน:** บอก path ของ PNG และแจ้งคำเตือนที่ยังเหลือ เช่น รูปความละเอียดต่ำ

## เขียนพรอมต์ให้ผู้ใช้เจนเอง

ถ้าผู้ใช้ขอแค่พรอมต์ (เช่น แปลงรูปตัวละครเป็น Semi-Realistic 3D ระดับ AAA เปลี่ยนท่าตามรูปที่ให้ สีหน้า ระยะภาพ) ให้อ่าน `references/character-prompts.md` แล้วตอบด้วยบล็อกพรอมต์ภาษาไทยที่เติมครบพร้อมคัดลอก ไม่ต้องเรียก API ไม่ต้องเรนเดอร์ กติกา

- ระบุชัดว่าภาพที่ 1 คือตัวละคร ภาพที่ 2 คือท่าทางเท่านั้น
- ถ้าผู้ใช้ทำโปสเตอร์เป็นชุด ให้แยกพรอมต์ต่อแผ่น (ท่า ระยะภาพ สีแสงขอบ ต่างกัน) แต่คงบล็อกตัวตนกับบล็อกสไตล์เหมือนกันทุกแผ่น
- ต้องการเอาภาพไปประกอบโปสเตอร์ต่อ ให้ใช้ฉบับอังกฤษแบบกรีนสกรีน ไม่ใช่ฉบับที่มีฉากหลัง
- เมื่อผู้ใช้ส่งภาพที่เจนแล้วกลับมา ค่อยเข้าขั้นตอนหลักตั้งแต่ข้อ 5

## เจนภาพด้วย AI

สูตรพรอมต์และวิธีเลือกรูปอ้างอิงอยู่ใน `references/image-prompts.md` อ่านก่อนเขียนพรอมต์ทุกครั้ง พรอมต์แปลงตัวละครจากรูปของผู้ใช้ (คงหน้า ชุด เปลี่ยนท่า) อยู่ใน `references/character-prompts.md`

1. เขียนพรอมต์ภาษาอังกฤษลงไฟล์ `<ชื่อ>.prompt.txt` ในโฟลเดอร์งาน
2. รัน `scripts/generate.ps1 -PromptFile hero.prompt.txt -Out hero_raw.png -Ref <รูปตัวละคร> -Aspect 4:5`
3. เปิดดูทุกภาพที่ได้ ตรวจหน้า มือ นิ้ว และว่าไม่มีตัวหนังสือหรือโลโก้แปลกปลอม
4. ภาพเกือบใช่ให้แก้ต่อจากภาพนั้น โดยใส่เป็น `-Ref` ตัวแรกแล้วสั่งเฉพาะจุดที่ต้องเปลี่ยน อย่าเจนใหม่ทั้งภาพ
5. ตัดพื้นด้วย `cutout.ps1 -Chroma` แล้วนำไปใส่ใน `heroes` หรือ `props`

กติกาการเจน:

- **ให้ AI ทำแค่ภาพ.** ห้ามสั่งให้เจนหัวข้อ ตัวเลข การ์ด หรือโลโก้ ส่วนเหล่านี้ให้เรนเดอร์จากสเปกเท่านั้น
- **ไอคอนไอเทมที่มีในเกมต้องใช้ไฟล์จริง.** เจนเฉพาะของที่ไม่มีไฟล์ และต้องแจ้งผู้ใช้ว่าเป็นภาพเจน
- **ค่าใช้จ่าย.** แจ้งราคาโดยประมาณก่อนเจน ลองท่าด้วย `-Model fast` (ประมาณ $0.05 ต่อภาพ 2K) และทำภาพจริงด้วย `-Model pro` (ค่าเริ่มต้น ประมาณ $0.134 ต่อภาพ 2K) รอบหนึ่งไม่เกิน `-Count 2` ถ้าเจนภาพเดียวกันเกิน 3 รอบแล้วยังไม่ผ่าน ให้หยุดเอาผลให้ผู้ใช้ดูก่อน
- **API key.** ถ้าสคริปต์แจ้งว่าไม่มี `GEMINI_API_KEY` ให้ผู้ใช้สร้างคีย์ที่ `https://aistudio.google.com/apikey` เปิด billing (คีย์ Free Tier เจนภาพไม่ได้ ได้ error 429 "limit: 0" ทดสอบแล้ว) แล้วตั้งค่าเองด้วย `setx GEMINI_API_KEY "<คีย์>"` ห้ามขอให้วางคีย์ในแชต ห้ามเขียนคีย์ลงไฟล์ และห้ามพิมพ์ค่าออกมา
- **ถ้า API error หรือถูกบล็อก** ให้รายงานข้อความจริงจากสคริปต์ แล้วปรับพรอมต์ถ้าเป็นเรื่องเนื้อหา อย่าส่งซ้ำแบบเดิม

## เจนตัวละครผ่าน Codex CLI (เมื่อผู้ใช้ขอเปลี่ยนท่า/ชุดทั้งตัว หน้าอาจเพี้ยน ถ้าแค่เปลี่ยนสีผม ของประดับ มุมกล้อง ใช้ Gemini ด้านล่างแทน)

Codex ในเครื่องผู้ใช้มีตัวเจนภาพในตัว ให้ภาพกรีนสกรีนสะอาด ไม่มีลายน้ำ และเก็บหน้าตัวละครของผู้ใช้ได้ถ้าส่งภาพใบหน้าใกล้ ๆ ไปด้วย ใช้สคริปต์ห่อไว้แล้ว ไม่ต้องเรียก `codex.exe` เอง:

```powershell
scripts\codex-gen.ps1 -Ref work\src\char.jpg,work\ai\face_char.jpg -Prompt $prompt -Out work\ai\gen_char.png
scripts\codex-gen.ps1 -Batch work\ai\jobs.json      # หลายตัวขนานกัน (templates\codex-jobs.example.json)
```

สคริปต์หา `codex.exe` เอง (อยู่ในส่วนเสริม VS Code ไม่ใช่ PATH) ส่งพรอมต์ทาง stdin (เพราะ `-i` กินอาร์กิวเมนต์ถัดไป) แยกโฟลเดอร์งานต่อ job ดึงภาพจาก `generated_images` ในล็อก และหยุดถ้าพรอมต์สั้นผิดปกติ (บั๊ก `+` ต่อ array ของ PowerShell) พรอมต์สำหรับตัวละครของผู้ใช้ดู `references/character-prompts.md` หัวข้อ Codex จากนั้น `cutout.ps1 -Chroma` และเปิดดูภาพจริงเทียบกับต้นฉบับ ถ้า Codex ปฏิเสธหรือถามกลับ สคริปต์รายงาน FAILED ห้ามหาทางเลี่ยง ใช้ตัวตัดจากภาพต้นฉบับแทน (`isolate.ps1` + `erase-white.ps1`)
## เจนและแก้ภาพผ่าน Antigravity CLI / Gemini (ไม่ต้องมี API key)

ใช้ผ่านบัญชีของผู้ใช้ ใช้ได้จริงทั้ง **แก้ภาพต้นฉบับเฉพาะจุด** (เปลี่ยนสีผม ของประดับหัว มุมกล้อง ย้ายพื้นเป็นเขียว) และ **เจนพื้นหลังโปสเตอร์** ผ่านสคริปต์ห่อ:

```powershell
scripts\agy-gen.ps1 -Ref work\src\a.jpg -Prompt $prompt -Out work\ai2\a_edit.png
scripts\agy-gen.ps1 -Batch work\ai2\jobs.json -TimeoutSec 480      # หลายงานขนาน (templates\codex-jobs.example.json รูปแบบเดียวกัน)
```

- ต้องมี `--add-dir` ของโฟลเดอร์งานเพื่อให้ agy อ่านรูปอ้างอิงในโหมด headless (สคริปต์ทำให้: คัดลอก ref เข้าโฟลเดอร์ชั่วคราวต่องาน) ถ้าไม่มี agy จะตอบว่า "read_file permission auto-denied" และไม่เจนอะไร ห้ามแก้ด้วย `--dangerously-skip-permissions`
- agy ตอบก่อนภาพเสร็จและเซฟไฟล์ชื่อของมันเองใน `%USERPROFILE%\.gemini\antigravity-cli\brain\<id>\` สคริปต์เฝ้าโฟลเดอร์นั้นแล้วคัดลอกภาพใหม่ให้ งานขนานเคยจับคู่สลับ (ภาพ Newbie ไปอยู่ชื่อ Gang) สคริปต์จึงสั่งให้ตั้งชื่อไฟล์ขึ้นต้น `jobN_` ให้ **เปิดดูภาพทุกใบ** ว่าตรงงานก่อนใช้
- ผลลัพธ์ ~1024 px (แนวตั้ง 768x1376) ใช้ `upscale.ps1` ช่วยให้คมก่อนขึ้นโปสเตอร์ ถ้าขยายเกิน 1.6 เท่าจะนุ่ม
- พรอมต์ที่ผ่านการทดสอบอยู่ใน `references/character-prompts.md` หัวข้อ "Gemini: แก้เฉพาะจุด มุมกล้อง และพื้นหลังฟุ้ง"
- ใช้กับตัวละครผู้ใหญ่ชัดเจนเท่านั้น ดู "ตัวละครหน้าเด็ก" ถ้า agy ปฏิเสธ ห้ามหาทางเลี่ยง

## สูตรโปสเตอร์ Support สไตล์ที่ผู้ใช้อนุมัติ (ทำตามลำดับนี้)

ผลลัพธ์: หน้า/ครึ่งตัวใหญ่เต็มภาพโทนมืดสีเดียว พื้นหลังรูปตัว X กระดาษฉีก หัวข้อขวา การ์ดโปร่งบนแผงมืดกลางล่าง ผู้ใช้บอก "ตอนนี้สวยแล้ว" รายละเอียดค่าทุกตัวอยู่ใน `references/support-styles.md` หัวข้อ "แนวที่ผู้ใช้ยืนยัน"

**เปิดดูภาพเป้าหมายก่อนเริ่มทุกครั้ง:** ผลที่ผู้ใช้อนุมัติ = `references/targets/approved-gang-red.jpg`, `approved-family-purple.jpg`, `approved-newbie-blue.jpg`, `approved-streamer-rose.jpg`, `approved-streamer-wide.jpg` (ใช้เทียบหลังเรนเดอร์) โปสเตอร์ต้นแบบที่ผู้ใช้ส่งมาเอง = `userref-gang.jpg`, `userref-gang-lady.jpg`, `userref-family.jpg` (ส่งเป็น ref ให้ Gemini ตอนเจนพื้นหลัง X-slab) เทมเพลตตรงกับสามใบนี้: Gang = `support-dense.json`, Family = `support-family.json`, Newbie = `support-face.json`

1. คัดลอกรูปตัวละครของผู้ใช้ไป `work\src\` (ห้ามลบต้นฉบับ) เปิดดูทุกรูป
2. เขียนไฟล์งานตาม `templates\gemini-jobs.example.json` แล้วรัน `scripts\agy-gen.ps1 -Batch jobs.json` ทีละขั้น (ขั้นถัดไปใช้ผลขั้นก่อนเป็น ref): **(ก)** แก้สีผม/ของประดับหัว + พื้นเขียว **(ข)** เปลี่ยนมุมเป็น medium close-up หัวถึงเอว **(ค)** เปลี่ยนเสื้อผ้า (ถ้าผู้ใช้สั่ง) **(ง)** พื้นหลัง X-slab ต่อสี (ขั้น ง ขนานกับขั้นอื่นได้) ทุกขั้นส่ง ref เดียว ใส่สีผมเป็นตัวพิมพ์ใหญ่ เปิดดูภาพทุกใบก่อนไปต่อ
3. `scripts\hero-prep.ps1` ต่อรูปตัวละคร แล้วคัดลอก `templates\support-dense.json` (16-28 ชิ้น แดง/Gang) `support-family.json` (16-28 ชิ้น ม่วง/Family) หรือ `support-face.json` (ไม่เกิน 15 ชิ้น ฟ้า/Newbie) ตั้ง `theme/accent2`, `background.image`, `heroes[0].src`, `title.lines`, `items.list` (ธีมที่มี: crimson violet cobalt rose toxic ember teal haunt pastel ocean; ระดับ Streamer ใช้ `rose` สีชมพู)
   - ตัวละครที่มีช่องว่างเล็กๆ ปิดล้อมในตัว (ระหว่างมัดผมกับคอ ห่วงแขน) ให้รัน `scripts\fill-holes.ps1 -In hero.png -Out hero_f.png` ก่อน ไม่อย่างนั้นลำแสงพื้นหลังจะโผล่ผ่านช่องเป็นแผ่นสีสว่างติดบนผมดำ (เจอกับ Streamer ผมดำ) แล้วค่อยใส่ไฟล์ที่ถมแล้วใน `heroes[0].src`
   - ถ้ายังไม่มีรายการของแจก **ห้ามเดาตัวเลข** ลบ `items`/`panel` ออกจากสเปกแล้วขอรายการจากผู้ใช้ (ตัวอย่าง `templates\support-streamer-noitems.json`, ภาพอนุมัติ `references/targets/approved-streamer-rose.jpg`) ตัวละครกว้างเพราะถือของ: ตั้ง `h` .9 `x` ~.4 ให้ขอบขวาไม่ชนหัวข้อ
   - `fill-holes.ps1` ใช้ `-Color` สีเดียวกับผมของตัวละคร (ผมดำ `#0c0809`, ไม่ใช่ไวน์เข้ม เพราะจะเห็นเป็นก้อนแยก) และรันกับ hero ที่ยังไม่ถม
   - ขนาดอื่น: `size` ใส่ `2:1` (2000×1000) ได้เลย (ภาพกว้าง/แบนเนอร์) ตัวอย่าง `templates\support-streamer-wide-noitems.json` / `references/targets/approved-streamer-wide.jpg`: hero `x` .29 `h` 1.0 ตัวละครเต็มความสูง, `column` x .66 ลงต่ำ (top .42) หลบแสงเด่นของพื้นหลัง, `footer` ย้ายไปใต้หัวข้อ (`x` .82 `align` center) พื้นหลังขอเป็น 2:1 (Gemini ให้ 1376×768 เอนจินครอปแบบ cover) พรอมต์อยู่ใน `references/character-prompts.md` หัวข้อ "พื้นหลังห้องสตรีมภาพกว้าง"
   - **สไตล์ "ฟุ้ง + ตกแต่งเยอะ + กริตหนา" (Streamer รอบล่าสุดที่ผู้ใช้สั่ง)**: พื้นหลังเจนจาก Gemini เป็นไอคอนตามธีมอาชีพ (สตรีมเมอร์: ป้าย LIVE แชตบับเบิลหัวใจ หูฟัง ไมค์ เว็บแคม จอยเกม กระดิ่ง หัวใจ/ดาวพิกเซล ริงไลต์ หน้าต่าง UI เปล่า คอนเฟตติ) โทนสีเดียว เว้นกลางภาพว่างไว้ให้ตัวละคร พรอมต์ใน `references/character-prompts.md` หัวข้อ "พื้นหลังตกแต่งเยอะตามธีมอาชีพ" ค่าเอนจิน: `grain` .34, `grainTop` .3, `bloom {blur 30, bright 1.35, saturate 1.2, alpha .26}`, `fx {sparks 26, bokeh 10, bokehFront 3}`, `vignette` .28 (สูงกว่านี้ขอบล่างมืดเป็นแถบดำ), `background.brightness` ~.84 วางตัวละครให้ไม่บังไอคอนแถวล่าง (ภาพกว้าง: ตัวละคร x .73 หัวข้อซ้าย; จตุรัส: ตัวละคร x .5 h .8 หัวข้อบนกลางภาพ) ตัวอย่าง `templates\support-streamer-*-noitems.json`
   - ตัวละครสีผมดำบนพื้นมืด: ลด `rim` เหลือ .3-.4, `grade` .2 และ `background.brightness` ~.72 ให้ผมไม่ซีด
   - รูปต้นฉบับจากครีเอเตอร์อื่นมักมีลายน้ำจาง/โลโก้ล่าง/ลายการ์ตูนลิขสิทธิ์ (Hello Kitty): พรอมต์ขั้น (ก) ลบให้ในประโยคเดียวกัน (เปลี่ยนกิ๊บเป็นกิ๊บดาวเงินทั่วไป) แต่ **ต้องแจ้งผู้ใช้เสมอ** ว่ามีลายน้ำ/ของลิขสิทธิ์ถูกลบ และควรขออนุญาตหรือให้เครดิตเจ้าของภาพ
4. `scripts\render.ps1` เปิดดูภาพเต็ม เช็กตามเช็กลิสต์ (ตัวละครถึงขอบล่าง ไม่มีแถบดำ การ์ดโปร่ง ฟุตเตอร์ไม่ชนการ์ด หน้าตัวละครไม่ถูกบัง) แก้แล้วเรนเดอร์ซ้ำ
5. เสื้อผ้าที่ใช้ในรอบที่ผู้ใช้อนุมัติ (ใช้เป็นตัวอย่างพรอมต์ ไม่ใช่กฎ): Gang คู่ = แจ็กเก็ตหนังไบเกอร์ดำ+เสื้อยืดขาว / เสื้อวาร์ซิตี้ดำแถบแดง, Family = คาร์ดิแกนถักสีไลแลคทับเสื้อยืดขาว+โชกเกอร์ดำ, Newbie = แจ็กเก็ตยีนส์ฟ้าทับเสื้อยืดขาว+สร้อยเงิน ไม่มีโลโก้/ตัวหนังสือ/ลายบนเสื้อ

## งานหลายชิ้น

ถ้าเป็นชุดเดียวกัน (เช่น Family, Gang, Lady) ให้คง `theme`, `layout`, `seed` และโลโก้ไว้ เปลี่ยนแค่รูป หัวข้อ และรายการ ตั้งชื่อไฟล์เป็น `<ชุด>-<ชื่อ>.png` งานที่ใช้หลายอัตราส่วนให้แยกสเปกต่อขนาด แล้วตรวจทุกขนาด

## เครื่องมือ

| สคริปต์ | หน้าที่ |
| --- | --- |
| `scripts/generate.ps1 -PromptFile p.txt -Out a.png [-Ref x.jpg,y.jpg] [-Aspect 4:5] [-Size 2K] [-Model pro\|fast] [-Count 1]` | เจนภาพด้วย Gemini รับรูปอ้างอิงได้ถึง 14 รูป ไม่เขียนทับไฟล์เดิม แสดงราคาโดยประมาณ |
| `scripts/render.ps1 -Spec x.json [-Out y.png]` | เรนเดอร์เป็น PNG บนการ์ดจอ แสดงชื่อ GPU ที่ใช้ และคำเตือน `POSTER-WARN` |
| `scripts/cutout.ps1 -In a.jpg -Out a.png [-Tolerance 26]` | ลบพื้นหลังเรียบจากขอบภาพเข้าหาตัวแบบ แล้วครอปชิด |
| `scripts/cutout.ps1 -In a.jpg -Out a.png -Chroma` | ลบกรีนสกรีน พร้อมลดสีเขียวที่ติดขอบ |
| `scripts/cutout-white.ps1 -In a.jpg -Out a.png -Keep "x,y ..." [-Free ..] [-Drop ..] [-Crop ..]` | ตัดตัวละครจากรูปต้นฉบับพื้นขาวแม้ใส่เสื้อขาว ใช้เส้น polygon (พิกัดพิกเซล) หลายรูปแบ่งด้วย `;` ภาพคู่/ตัวมืดใส่ `-Pocket 0 -Halo 0` |
| `scripts/agy-gen.ps1 -Ref a.jpg[,b.jpg] -Prompt "..." -Out x.png` หรือ `-Batch jobs.json` | เจน/แก้ภาพด้วย Gemini ผ่าน Antigravity CLI (ไม่ต้องมี API key) หลายงานขนาน ตั้งชื่อไฟล์ให้ขึ้นต้นด้วย `jobN_` เพื่อจับคู่ผลกับงาน และคัดลอกให้ที่ `-Out` ตรวจผลด้วยตาทุกครั้ง |
| `scripts/hero-prep.ps1 -In work\ai2\char_outfit.png -Out work\hero_char.png` | ขั้นเดียวจากภาพพื้นเขียวของ Gemini: ตัดพื้นเขียว → ครอปแนวนอนให้ชิดตัว (คงความสูงเต็ม) → ขยาย + ลับความคม พร้อมใส่ใน `heroes[0].src` |
| `scripts/fill-holes.ps1 -In hero.png -Out hero_f.png [-Color '#1a0610' -MinArea 150]` | หาช่องโปร่งใสที่ถูกล้อมอยู่ในตัวละคร (ไม่เชื่อมกับขอบภาพ) แล้วถมสีเข้ม ให้ช่องระหว่างผมกับคอดูเป็นเงา ไม่ใช่แผ่นพื้นหลังสว่าง ใช้หลัง hero-prep |
| `scripts/upscale.ps1 -In hero.png -Out hero_x.png [-Scale 1.6]` | ขยายตัวละครที่ตัดแล้ว + ลับความคม (ภาพ AI ~1000 px ขึ้นโปสเตอร์ 1920) |

**เรนเดอร์บนการ์ดจอเท่านั้น.** ถ้า Chrome ใช้การ์ดจอจริงไม่ได้ `render.ps1` จะหยุดและไม่สร้าง PNG ห้ามแก้ด้วยการเปิดซอฟต์แวร์เรนเดอร์หรือใส่ `--disable-gpu` ให้รายงานข้อความ error ให้ผู้ใช้แทน

**รูปพื้นขาว + เสื้อขาว.** `cutout.ps1` ตรง ๆ ทำเสื้อและมือเป็นรู ให้เลือก (1) `cutout-white.ps1` ตัดจากพิกเซลต้นฉบับด้วยเส้น polygon ที่วาดตามขอบ (คมที่สุด ไม่เปลี่ยนตัวละคร) หรือ (2) ให้ Gemini ทำพื้นเขียวจากภาพนั้นด้วย `agy-gen.ps1` แล้ว `cutout.ps1 -Chroma` (ใช้เมื่อผู้ใช้ขอเปลี่ยนสีผม/ของประดับ/มุมกล้องด้วย) ตรวจลายน้ำศิลปินก่อนใช้ทุกครั้ง ดู `references/support-styles.md`

`-Tolerance` เริ่มที่ค่าเดิม แล้วเพิ่มทีละน้อย เสื้อผ้าสีเดียวกับพื้นหลังจะเริ่มเป็นรูเมื่อค่าสูงเกินไป มาสคอตพื้นเทาเข้มตอนทดสอบใช้ 40 ได้ แต่ 55 ทำให้กางเกงดำเป็นรู เงาบนพื้นอาจติดมาด้วย

## เช็กลิสต์

- ไม่มี `POSTER-ERROR` และคำเตือนทุกข้อได้รับการจัดการหรือแจ้งผู้ใช้แล้ว
- หัวข้ออ่านออกเมื่อย่อเหลือขนาดในฟีดมือถือ
- ใบหน้าตัวละครไม่ถูกตัวหนังสือ การ์ด โลโก้ หรือเอฟเฟกต์บัง
- สระและวรรณยุกต์ไทยไม่ถูกตัด ไม่ซ้อนบรรทัด
- ชื่อ จำนวน วันที่ และลิงก์ตรงกับที่ผู้ใช้ให้ทุกตัวอักษร ปีไทยและปี ค.ศ. ไม่สับสนกัน
- ขอบ cut-out ไม่มีกรอบสีพื้นเดิม ไม่มีรู
- สายฟ้าและประกายไม่วิ่งผ่านข้อความ
- ภาพเจนไม่มีนิ้วเกินหรือมือบิด ไม่มีตัวหนังสือมั่ว ลายน้ำ หรือโลโก้แปลกปลอม

## กฎที่ห้ามข้าม

**ต้นฉบับ.** รูปอ้างอิงเป็นงานของหลายเซิร์ฟเวอร์ ใช้ได้แค่เป็นทิศทางสไตล์ ห้ามนำภาพ โลโก้ ชื่อกิจกรรมเฉพาะ หรือตัวละครในนั้นมาใส่งานใหม่ โลโก้บนโปสเตอร์ต้องเป็นของเจ้าของงานเท่านั้น เมื่อใช้เป็น `-Ref` ใส่ได้ไม่เกิน 1 รูปเพื่ออ้างอิงแสงและอารมณ์ และต้องตรวจว่าภาพเจนไม่ได้ลอกตัวละครหรือองค์ประกอบมา

**รูปของคนอื่น.** ใช้รูปที่เจ้าของงานส่งมาเพื่อทำงานนั้น อย่าหยิบรูปจากงานลูกค้าคนหนึ่งไปใช้กับอีกคน ถ้ารูปเป็นบุคคลจริง อย่าเขียนข้อความที่ทำให้ดูเหมือนบุคคลนั้นรับรองสิ่งที่เขาไม่ได้รับรอง ตัวการ์ตูนหรือแบรนด์ลิขสิทธิ์ที่ติดมาในรูปควรแจ้งผู้ใช้ก่อนใช้โปรโมต

**ไฟล์ของผู้ใช้.** ห้ามลบรูปต้นฉบับของผู้ใช้เพราะคิดเองว่า "ไม่ได้ใช้" (เคยลบรูปตัวละครที่ผู้ใช้ตั้งใจกลับมาใช้ แล้วกู้ไม่ได้) ทำงานกับสำเนาใน `work\src\` ถ้าผู้ใช้สั่งลบ ให้ระบุชื่อไฟล์ทีละชื่อให้ยืนยัน หรือย้ายไป `_old` ล้างได้เฉพาะไฟล์ชั่วคราวที่ skill สร้างเอง

**ข้อมูลจริง.** ห้ามแต่งของรางวัล จำนวน ราคา วันที่ หรือลิงก์เอง ข้อมูลที่ขาดให้ถาม ถ้าต้องวางตัวอย่างให้เห็นเลย์เอาต์ต้องบอกชัดว่าเป็นข้อความสมมติ

**รายงานตามจริง.** ถ้าเอฟเฟกต์ไม่ถึงระดับงานรีทัชมือหรือรูปต้นทางแตก ให้บอกตรง ๆ พร้อมระบุว่าต้องใช้รูปแบบไหนเพิ่ม
