# Weapon Anatomy

ตัวเลขทั้งหมดอ่านจาก `.ydr` ของสกินที่ไม่ได้ล็อกในเซิร์ฟเวอร์ (elys, extreme, lego, eclipse, halloween, white_rabbit) หน่วยเป็นเมตร สถิติทั้งเซิร์ฟเวอร์ที่อัปเดตได้อยู่ใน `server-catalog.md`

## สกินมีสองแบบ

| แบบ | ลักษณะ | ตัวอย่าง |
| --- | --- | --- |
| ปั้นโมเดลใหม่ | 5k–40k tris ฝัง texture หรือมี `.ytd` คู่ | elys, extreme, lego |
| เปลี่ยน texture บนโมเดลเดิม | `.ydr` ราว 4 KB (106 tris, `_hi` 282 tris) กับ `.ytd` ชื่อเดียวกัน | `w_me_poolcue_kradikjuu`, `_event`, `_lv1` |

แบบที่สองเบาและเร็ว เหมาะกับสกินแก๊งหรือสกินระดับ ถ้าโจทย์ไม่ต้องการรูปทรงใหม่ ให้เสนอแบบนี้ก่อน

## ทิศแกน

- อาวุธระยะประชิด: แกนยาว = `+Z` จุดกำเนิด (origin) อยู่ตรงมือ ปลายอาวุธไป `+Z` ก้นด้ามไป `-Z`
  - **Bottle / Knife (มีดสั้น / คารัมบิต):** ส้นด้าม (หรือห่วงนิ้ว) อยู่ที่ `Z ≈ -0.048 ถึง -0.055`, จุดกึ่งกลางด้ามจับตรงมือ (`Z = +0.0123`) ต้องอยู่ตรงแกน `X = 0, Y = 0` พอดี (ห้ามให้ใบหรือด้ามเอียงทแยงออกนอกแกน `+Z`), กระบังมือ (guard/tsuba) ต้องเริ่มที่ `Z ≈ +0.032 ถึง +0.038` ชิดเหนือสันมือ และปลายใบมีดอยู่ที่ `Z ≈ +0.24 ถึง +0.28` ความหนา `Y` ของด้ามและใบประมาณ `0.020–0.042 ม.`
  - **Machete:** ส้นด้ามอยู่ที่ `Z ≈ -0.045`, ร่องนิ้วด้ามจับอยู่ที่ `Z = -0.035 ถึง +0.035` (`X = 0, Y = 0`), กระบังมืออยู่ที่ `Z ≈ +0.038 ถึง +0.080` และปลายใบมีดอยู่ที่ `Z ≈ +0.41 ถึง +0.48` ความหนา `Y` ประมาณ `0.025–0.046 ม.`
  - **Poolcue:** ด้ามจับช่วงมือขวา (`Gun_GripR` ที่ `Z = +0.0123`) และมือซ้าย (`Gun_GripL` ที่ `Z = +0.4127`) ต้องเป็นทรงกระบอกเรียบศูนย์กลางอยู่ที่ `(X = 0, Y = 0)` ส้นด้ามอยู่ที่ `Z ≈ -0.10 ถึง -0.13`
- ใบมีด: แบนในระนาบ XZ ความหนาคือ Y คมหันไป `+X`
- สนับมือ: แบนในระนาบ YZ ความหนาคือ X (`[-0.011, +0.011]`) แถวนิ้วเรียงตาม Z (`[-0.068, +0.068]`) **สำคัญ:** สันฝ่ามือต้องอยู่ฝั่ง `+Y` (`+0.022 ถึง +0.025`) และรูสอดนิ้ว 4 รู + เดือย/หนามด้านหน้าต้องชี้ไปทาง `-Y` (`-0.065 ถึง -0.080`) ห้ามกลับหัว 180°
- ปืน: ปากกระบอกไป `+X` ด้านบนคือ `+Z` ด้ามลง `-Z` ด้ามปืนต้องครอบ `Gun_GripR (-0.0948, -0.0167, -0.0614)` ไกปืนอยู่แถว `(X = 0, Z = -0.008)` ความหนา `Y` ของตัวปืนต้องไม่เกิน `0.034–0.052 ม.` และความสูง `Z` ช่วง `[-0.11, +0.11]`
- ข้อยกเว้นที่พบ: `white_rabbit_poolcue` วางแกนยาวบน Y ห้ามเลียนแบบ

## มาตรฐานรูปไอคอนสกินใน `1nfx_assetsimg/items/` (Dual Icon Standard 96×96)

ทุกสกินต้องมีไอคอน `96×96` RGBA พื้นโปร่งใสครบ **2 ชุด** ใน `1nfx_assetsimg/items/` และ `weapon_<id>/assets/items/`:
1. **`COMPONENT_SKIN_<SLOT>_<ID>.png` (รูปอาวุธเดี่ยวพร้อมเงาตกกระทบ)**:
   - **Bottle / Knife / Machete / Poolcue**: วางเฉียงทแยงมุมตามเข็มนาฬิกา (`+32° ถึง +42°`) ด้ามจับอยู่มุมล่างซ้าย ปลายอาวุธชี้ออกมุมบนขวา คมมีดหันลงด้านขวาล่าง
   - **Knuckle**: วางแนวนอน (`Horizontal`) สันฝ่ามืออยู่ด้านล่าง รูสอดนิ้วทั้ง 4 และหนาม/หัวปีศาจชี้ขึ้นด้านบน (`+Y` ของภาพชี้ขึ้น)
   - **Revolver**: ด้ามปืนอยู่ด้านล่างซ้าย ปากกระบอกปืนชี้เฉียงขึ้นไปทางขวาบน (`~42°`)
2. **`skin_<slot>_<id>.png` (รูปแพ็กการ์ด `"CARD SKIN"` Blister Pack 3D)**:
   - ใช้การ์ด `"CARD SKIN"` เอียงตามเข็มนาฬิกา `~16°` พร้อมพลาสติกใสครอบด้านหน้า (`blister reflection`)
   - อาวุธทุกชิ้นวางอยู่ภายในกรอบพลาสติกใสเหนือข้อความ `"CARD SKIN"` (สำหรับ `Knuckle` ให้วางตั้งตามแนวกล่องพลาสติกโดยหันด้านหนามไปทางซ้ายบนและสันฝ่ามืออยู่ด้านขวา)

## Skeleton

ทุกสกินคง bone ของอาวุธต้นฉบับไว้ ค่าตำแหน่งเป็น local ต่อ parent

| ช่อง | Bones |
| --- | --- |
| Melee ทั้งหมด | `Gun_Root (0,0,0)` → `Gun_GripR (-0.0456, 0.0020, 0.0123)` → `Gun_Main_Bone (0.0425, -0.0195, -0.0072)` |
| Poolcue | เหมือน melee + `Gun_GripL (0, 0, 0.4127)` |
| Revolver | 10 bones: `Gun_Root`, `Gun_GripR (-0.0948, -0.0167, -0.0614)`, `Gun_Main_Bone`, `gun_crane`, `gun_cylinder`, `Gun_VFX_Eject`, `WAPClip`, `Gun_Muzzle (0.2468, 0, 0.0389)`, `Gun_Trigger_Pr`, `Gun_Hammer` |

**กฎสำคัญของ Skeleton ใน `.ydr` (`export_ydr.py`):**
- `Gun_GripR` ใน GTA V **ไม่ได้มี rotation เป็น identity `(0,0,0,1)`**:
  - Melee / Poolcue: `Gun_GripR` มี `rot = (0.618959, -0.106120, 0.017754, 0.778019)` และ `Gun_Main_Bone` มี rotation ผกผัน `(-0.618959, 0.106120, -0.017754, 0.778019)` ทำให้ world matrix ของ `Gun_Main_Bone` (bone index `2` ที่ผูก vertex ทั้งหมด) เป็น Identity (`Inv[2] = Identity`) พอดี ถ้าใส่ `(0,0,0,1)` อาวุธจะบิดผิดมุม ~78° ตอนถือในมือ
  - Revolver: `Gun_GripR` มี `rot = (0.655222, -0.003139, 0.038073, 0.754470)` และ `Gun_Main_Bone` มี rotation ผกผัน `(-0.655223, 0.003139, -0.038074, 0.754469)`
- Bone tag ต้องคำนวณด้วย `ElfHashUpperCase % 0xFE8F + 0x170` (ไม่ใช่ `joaat & 0xFFFF`): `Gun_Root=0`, `Gun_GripR=18308`, `Gun_Main_Bone=3360`, `Gun_GripL=18302`, `gun_crane=18771`, `gun_cylinder=3562`, `Gun_VFX_Eject=28405`, `WAPClip=1477`, `Gun_Muzzle=17833`, `Gun_Trigger_Pr=56099`, `Gun_Hammer=24730`
- `ChildParentIndices` ที่ `skel + 0x40` ต้องไม่เป็น NULL และ `BoneHashTable` ต้องรวม `Gun_Root` (`idx=0, tag=0`) ด้วย
- ไฟล์ `.ytd` คู่กับ `.ydr` ต้องมี `grcTextureDX11` + ข้อมูล DXT5 จริง (`texCount >= 1`, `sf=0x00020000`, `gf=0xD0000086`) ห้ามสร้างไฟล์ `.ytd` ว่างขนาด 66 ไบต์ (`texCount = 0`) เด็ดขาดเพราะจะทำให้เกมหา texture ไม่เจอ

## ไอเดียการออกแบบตามช่อง

ทุกตระกูลใน `style-families.md` ใช้โครงเดียวกัน คือ "เนื้อวัสดุสองโทน + ลวดลายนูนหนึ่งชนิด + ของห้อยหนึ่งชิ้น"

- **Poolcue/Bat:** แบ่ง 4 โซน คือด้ามจับ, คอลลาร์, ตัวก้าน, ปลาย จุดเด่นอยู่ด้านบน (`topper`: `mascot`, `wings`, `shell`, `dragon`) หรือพันเป็นเกลียว (`wrap`: `scale`, `dragon`, `thorn`, `chain`)
- **Bottle:** เลือกรูปทรงผ่าน `style.bottle_type`: `bottle` (ขวดมงกุฎหยัก), `scepter` (คทาหัวใจ/ปีกแบบ ELYS/BALDWIN), `balisong` (มีดผีเสื้อแบบ RYX), `war_pick` (เคียวศึกสองหัวแบบ OUTCAST), หรือ `katana` (ดาบซามูไรยาว ~0.80 ม.)
- **Machete/Knife:** ใบมีด 3D สองชั้น (คมหน้าเรียว + สัน shinogi + ร่องเลือด `fuller`) วางลายบนหน้าใบและด้ามจับร่องนิ้ว (`handle()`)
- **Knuckle:** เลือกรูปทรงผ่าน `style.knuckle_type`: `standard` (สนับมือ 4 ห่วง + เดือย), `blade_knuckle` (สนับมือติดใบมีดคู่แบบ RYX), `lace_fan` (สนับมือพัดลูกไม้แบบ BALDWIN), หรือ `jaw_shield` (สนับมือเกราะกรามปีศาจแบบ OUTCAST)
- **Revolver:** ลายสองจุดที่สไลด์และด้าม รองรับ `optic` (ศูนย์เล็งโฮโลแกรม), `tac_light` (ไฟฉายใต้ลำกล้อง), `dragon_slide` (หัวมังกรบนสไลด์), และ `wings_slide` (ปีกข้างสไลด์) ของประดับต้องไม่บังศูนย์เล็ง
