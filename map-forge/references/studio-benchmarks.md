# Studio Benchmarks & Map Archetypes

ตัวเลขและแนวทางสถาปัตยกรรมด้านล่างถอดบทเรียนจากการวิเคราะห์เชิงวิศวกรรมของแมพ FiveM ระดับโปรดักชัน 12 ชุด ครอบคลุม 6 ประเภทงานหลัก เพื่อใช้เป็นเกณฑ์ตั้งงบ (Budget Ceiling) และมาตรฐานหน้าตาก่อนปั้นทุกครั้ง

## 1. งบมาตรฐานตามประเภทแมพ (Target Budgets)

| ประเภทแมพ | Custom `.ydr` | Hero Shell Tris | Total Custom Tris | Shared `.ytd` VRAM | Disk รวม | Entities รวม (Custom : Vanilla) | Collision |
| --- | --- | --- | --- | --- | --- | --- | --- |
| **1. Sky AFK / Floating Plaza** | 1–12 ชิ้น | 2,000–18,000 | <= 35,000 | **1.0–5.0 MB** (สูงสุด 8 MB) | 1.5–6.0 MB | 80–400 (5–15% : 85–95%) | Dual (Embedded + Static World `.ybn`) |
| **2. Spawn / Select Lobby** | 1–4 ชิ้น | 1,800–12,000 | <= 20,000 | **0.6–2.5 MB** | 1.0–3.0 MB | 50–700 (2–15% : 85–98%) | Dual (Embedded + Static World `.ybn`) |
| **3. Airdrop / Warzone PvP Arena** | 1–3 ชิ้น | 2,000–10,000 | <= 15,000 | **0.8–4.0 MB** | 1.0–3.0 MB | 40–260 (2–10% : 90–98%) | Static `.ybn` ต่อโซน (ทำ 1 `.ydr` แชร์หลาย `.ymap` ได้) |
| **4. City Garage / Town Hub** | 4–16 ชิ้น | 7,000–15,000 | <= 45,000 | **0.8–4.0 MB** | 4.0–8.0 MB | 500–2,500 (2–5% : 95–98%) | Static `.ybn` แยก `hi@`/`ma@` + Embedded |
| **5. Rebel / Industrial Outpost** | 2–5 ชิ้น | 4,000–15,000 | <= 25,000 | **0.7–2.0 MB** | 1.0–5.0 MB | 300–2,200 (1–5% : 95–99%) | Static `.ybn` + Embedded |
| **6. City Building / Hospital / MLO** | 5–15 ชิ้น | 10,000–30,000 | <= 90,000 | **2.0–8.0 MB** | 6.0–15.0 MB | 400–2,500 + MLO Rooms/Portals | MLO Collision + Exterior `hi@` `.ybn` |

> [!WARNING]
> **Anti-Pattern ที่ต้องหลีกเลี่ยงเด็ดขาด (ตรวจพบในงานตัวอย่างที่ไม่ผ่านเกณฑ์และบทเรียนจริง):**
> - **Raw CAD/SketchUp Dump ทะลุแสน tris:** เช่น shell เดียว 165,000–640,000 tris กินดิสก์ 30+ MB ทำให้กระตุกทันทีเมื่อมีผู้เล่นยืนรวมกัน ห้ามเกิน 40,000 tris ต่อ shell เดียวเด็ดขาด
> - **ใช้ DXT5 กับภาพทึบทั้งหมด + 1024px ทุกช่อง:** ทำให้กิน VRAM เกิน 14 MB ทั้งที่มีแค่ 12 รูป หากแปลงผิวทึบเป็น PCA DXT1 และย่อสีเรียบเป็น `4x4`–`32x32` จะลด VRAM ลงได้ 60–85% โดยภาพคมกว่าเดิม
> - **ปั้นต้นไม้/พุ่มไม้เองด้วย primitive หรือ metaball:** ดูเป็นการ์ตูนพลาสติก กิน tris ฟรี และไม่มีลม/เงาใบไม้เหมือน GTA V
> - **หน้าตา "เหมือน AI ทำ / บ้านการ์ตูน":** ห้ามทำเกาะจานบินกลมแบน + บ้านกล่องแปะหน้าต่างสีเหลืองแบน + ลายไม้คลื่น `sin()` + กระบะดินสีน้ำตาลโคลน ให้ใช้ภาษาสถาปัตยกรรมร่วมสมัยจริง (ลานสี่เหลี่ยม/เล่นระดับ `110–140m × 50–65m`, กระจก Curtain Wall ลึกเห็นห้อง 3 มิติจริงด้านใน, ระแนงไม้ลายเส้นตรง anisotropic, หินขัด Terrazzo/คอนกรีตสถาปัตย์รอยต่อบาง 2px, สนามหญ้าสีเขียวจริง และสระสะท้อนน้ำ)

## 2. รูปแบบการจัดสถาปัตยกรรมไฟล์ (3 Patterns)

### Pattern A: Single Hero Shell + Heavy Vanilla Dressing (เร็วสุด ลื่นสุด)
- **เหมาะกับ:** Sky AFK Plaza, Spawn Lobby, Warzone Arena, Rebel Hangar
- **โครงสร้าง:** 1–2 `.ydr` หลัก (ลาน+ขอบทาง+กระบะ+ศาลา/โครงหลังคา รวมเป็น draw calls น้อยที่สุด ~10–15 materials) + 1 shared `.ytd` + 1 static `.ybn` + 1 `.ymap` ที่วาง prop GTA V 50–380 ชิ้น
- **ข้อดี:** Draw call ต่ำมาก (ลื่น 180–200 FPS แม้คนยืน 100 คน), UV ต่อเนื่องไร้รอยต่อพื้น

### Pattern B: Modular Architectural Kit + Shared PBR YTD (ปรับแก้ผังง่ายที่สุด)
- **เหมาะกับ:** Sky Campus / Theme Park / Modular Courtyard ที่ต้องการขยับศาลา ซุ้มประตู สะพาน บ่อน้ำพุ และซ้ำชิ้นเดิมได้ (instancing)
- **โครงสร้าง:** 6–12 modular `.ydr` (เช่น ลานหลัก, สะพาน, ศาลา, ซุ้มประตู, น้ำพุ, ซุ้มพัก, เสาไฟแบรนด์) แชร์ 1 `.ytd` เดียว + 1 static world `.ybn` รวมกล่องชนทุกชิ้น + 1 `.ymap` ผสม custom instances กับ vanilla GTA V props
- **ข้อดี:** แก้ผังหรือทำสาขาใหม่ได้จากการแก้ `map-spec.json` โดยไม่ต้องปั้นลานใหม่ทั้งหมด และ instancing ช่วยประหยัด memory

### Pattern C: City Replacement / Multi-YMAP Split + MLO
- **เหมาะกับ:** โรงพยาบาล, การาจกลางเมือง, อาคารสภา/ฐานแก๊งที่มีห้องภายใน
- **โครงสร้าง:** แยก `.ymap` ตามระยะโหลด (`_base`, `_outside`, `_inside`, `_light`, `_strm_0`, `_long_0`, `_critical_0`) แยก `.ybn` เป็น `hi@` (ละเอียดระยะใกล้) / `ma@` (หยาบระยะไกล) และประกาศห้อง/ประตูใน `.ytyp` แบบ `ArchetypeDefinitionMlo` (`rooms`, `portals`, `entities`)

### Pattern D: Enclosed 4-Faction Sky-Stadium PvP / Airdrop Arena (ถอดบทเรียนจาก `sadddsa/ubbu_airdrop` & `ubbu_warzone_freeforall`)
- **เหมาะกับ:** Airdrop Battle Royale 60–128 คน, Team PvP Arena, School War Event ที่มีหลายโซน (`GANG` / `FAMILY` / `CITIZEN`) และวงบีบ `startRadius = 100–120m`
- **โครงสร้างระดับโปรดักชัน (200 FPS แม้คนชน 128 คน):**
  - **1 Hero Stadium Shell (`.ydr`, 12,000–32,000 tris) + 1 Shared `.ytd` (1.5–3.5 MB VRAM)** ใช้ซ้ำได้ทั้ง 3 โซนผ่าน `.ymap` + `.ybn` รายโซน (`flags = 32`, `<= 35` entities ต่อโซน!)
  - **ลานต่อสู้วงกลมเปิดโล่ง (`R = 95–122m` พอดี `startRadius`):** พื้นหญ้าตัดสลับแถบสเตเดียมเรียบสนิท `90%+` ของพื้นที่ (ห้ามวางสิ่งกีดขวางกลางโซน `R = 0..14m` เพราะสคริปต์วาร์ปผู้เล่นที่ `offset 3..5m` และวางกล่องแอร์ดรอปที่ `(0, 0, Z_config + z_offset)`!)
  - **กำแพงสเตเดียม 4 ควอแดรนต์ประจำบ้าน/ฝ่าย (N/E/S/W ฝ่ายละ 90°):** สูง `12–16m` พร้อมป้ายบ้านขนาดใหญ่ + กำแพงชนล่องหนสูง `24m` กันโดดออกนอกสนาม 100%
  - **จุดตกแต่งรอบนอกเหนือกำแพง (`R > R_wall + 10m`):** เสาไฟสเตเดียม 8 ต้น + บอลลูนลมร้อนลอยฟ้านอกระยะชน + ซุ้มมุมสนาม 4 มุมชิดขอบกำแพง — ได้ความอลังการแบบไม่กิน FPS และไม่เกะกะทางวิ่ง PvP
  - **Animated Prop Clip (`.ycd`):** สำหรับกล่องแอร์ดรอปหรือโลโก้หมุนลอยฟ้า สตูดิโอผูก `clipDictionary` ใน `.ytyp` คู่ไฟล์ `.ycd` (3–55 KB) เพื่อให้โลโก้/กล่องขยับได้เองโดยไม่ต้องใช้สคริปต์ Lua
- **City Replacement Reference (`sadddsa/ubbu_mainschool`):** แยก `.ybn` เป็น `dt1_13_0.ybn`, `hi@dt1_13_0.ybn` (ละเอียด), `ma@dt1_13_0.ybn` (ระยะไกล) และวาง `vw_lodlights` / `vw_distlodlights` แยกจาก `.ymap` หลัก

### Pattern E: Organic Sky/Sea Plaza Island + Themed Prop Dressing (ถอดจากคลิปโชว์เคสของผู้ใช้ 2026-11-22)
- **เหมาะกับ:** ลานกลางเมือง/Spawn Hub ลอยฟ้าหรือกลางทะเลที่ใช้วางชุด prop แบรนด์ (ATM, โต๊ะคราฟต์, marker) และเป็นฉากถ่ายโปรโมต
- **ผัง:** เกาะสี่เหลี่ยมมุมมนราว `120–160m` ขอบเป็นเส้นโค้งไหลทั้งหมด ไม่มีมุมฉาก; ลานวงกลมกลาง `R = 25–35m` พื้นกระเบื้องเรียบโล่ง 80%+ มีเส้นทางเดินโค้งสีเข้มฝังพื้นเป็นลายวงซ้อน (ทำด้วย decal/แถบ mesh ไม่ใช่ texture ใบใหญ่)
- **Hero 3 ชิ้นที่ทำให้ดูแพง:** (1) ต้นไม้ใหญ่ต้นเดียวท้ายลานบนแท่นบันไดวงกลม 3–4 ขั้นพร้อมโลโก้ฝังพื้น (2) โครงเสี้ยวจันทร์/วงแหวนโปร่งเรืองแสงสูง `15–20m` โอบต้นไม้ (3) หลังคาทรงใบไม้/คลื่นโค้งยาวสองข้างลานเป็นโครงซี่ไม้ซ้ำ ๆ (instance ชิ้นเดียววางซ้ำตามเส้นโค้ง) ปิดด้วยแผ่นสีเขียวเทอร์ควอยซ์
- **ขอบเกาะ:** กำแพงไม้ลอนคลื่นสูงต่ำไล่ระดับ `2–8m` ทำหน้าที่ทั้งฉากหลังและกันตก มีซุ้มโค้งทางเข้า 2–4 จุดติดป้ายชื่อทางเข้า กระบะต้นไม้เตี้ยขอบโค้งวางเป็นจังหวะตามขอบลาน
- **แสงกลางคืน:** แถบ emissive อุ่นฝังขอบบันไดและขอบกระบะ, เสาไฟแท่งคู่แนวตั้งสูง `2–3m` ทุก `12–18m`, โครงจันทร์เป็น `emissivenight.sps`; พื้นลานคง `G = 0` ให้มืดจริงเพื่อให้ prop ที่มี emissive เด่น
- **โซนวาง prop:** เว้นพื้นเรียบรัศมี `>= 2.5m` รอบทุกจุดวาง prop แบรนด์ วางเป็นกลุ่ม 3–5 ชิ้นชิดขอบลาน หันหน้าเข้ากลาง ห่างกัน `3–4m` กลางลานปล่อยโล่งสำหรับคนรวมตัว
- **งบ:** Hero shell `18,000–40,000` tris แบ่ง 4–6 `.ydr` (พื้น, ขอบ+กำแพง, หลังคาใบไม้ instance, โครงจันทร์, แท่นต้นไม้), Shared `.ytd` `2–5 MB`, พุ่มไม้/ต้นไม้ใช้ prop แท้ GTA V ตาม `gta-prop-catalog.md`; แมพกลางทะเลต้องมี `.ybn` พื้นเกาะเต็มและกำแพงชนล่องหนรอบขอบ
- **พื้นผิวโค้ง:** ชิ้นโค้งทั้งหมดใช้ World-Scale Tiled UV ตามความยาวเส้นโค้ง (unwrap follow-active-quads) ไม่ใช่ smart UV เพื่อให้ลายไม้/กระเบื้องวิ่งตามแนวโค้ง

## 3. เทคนิค Texture Tiering (คุม VRAM 0.6–4 MB แต่คมกริบ)

จากการตรวจสอบ `.ytd` ของสตูดิโอชั้นนำ พบหลักจัดสรรขนาด texture 4 ระดับ:

| ระดับ | ขนาด (px) | รูปแบบ | ใช้กับ |
| --- | --- | --- | --- |
| **Micro-Swatch** | `4x4` – `32x32` | DXT1 | สีเรียบของเสาเหล็ก, ขอบอะลูมิเนียม, trim, กระจกสีพื้น, ผิวสีเข้ม (กิน VRAM แทบเป็น 0 KB!) |
| **Secondary Tiled** | `256x256` | DXT1 | ดินกระบะ, ปูนฉาบเรียบ, หลังคา, ขอบถนน, Normal/Spec เสริม |
| **Primary Architectural Tiled** | `512x512` | DXT1 | หินปูพื้น (Terrazzo/Travertine/Paver), ไม้ระแนง (Cedar), คอนกรีตสถาปัตย์, หินอ่อน, หญ้าจริง |
| **Hero Surface / Brand Decal** | `1024x1024` | DXT1 (ทึบ) / DXT5 (โปร่ง) | โลโก้เซิร์ฟเวอร์, ป้ายต้อนรับ, แผนผัง/กราฟิกพื้นจุดศูนย์กลาง (จำกัดไม่เกิน 1–3 ใบต่อแมพ!) |

**กฎความหนาแน่นพิกเซล (Texel Density):**
- พื้นทางเดิน/ลาน: ตั้ง tile scale ให้ 1 แผ่น `512x512` ครอบคลุม **1.5–2.5 เมตร** (= 200–340 px/m)
- ผนัง/เสา/ไม้ระแนง: 1 แผ่น `512x512` ครอบคลุม **1.5–3.0 เมตร**
- **ห้าม** ยืดภาพ `512x512` เดียวคลุมทั้งลาน 60 เมตรเด็ดขาด

## 4. หลักออกแบบสถาปัตยกรรมให้ดู "แพงและสมจริง" (Visual Craft Checklist)

ถอดจากงานโปรดักชันที่ผ่านตาจริง (Sky Lobby, Garage Terrace, Steel Truss Hangar, Hospital Exterior):
1. **เล่นระดับพื้น (Stepped Elevation & Curbs):** อย่าทำแผ่นสี่เหลี่ยมแบนแผ่นเดียว ให้แบ่งระดับอย่างน้อย 2–3 ระดับ เช่น ลานกลางยกระดับ +0.18m พร้อมขอบหินบัว (beveled curb), ขั้นบันได 2–3 ขั้นพร้อมราวกันตกเหล็กท่อ (tubular handrail), กระบะต้นไม้ยกขอบหรือหลุมปลูกโค้งเว้า (organic kidney/oval planter cutouts)
2. **โครงสร้างที่มีเหตุผลทางวิศวกรรม (Structural Framing):** ศาลา/กันสาด/หลังคาต้องมีเสาฐาน (plinth/pedestal), คานรับ (beams), จันทันหรือโครงถักเหล็ก (trusses + X-bracing), เชิงชาย (fascia/eaves overhang) — โครงถักเหล็กแบบเปิดใช้แค่ ~3,000–12,000 tris แต่ดูสมจริงระดับ AAA
3. **เส้นนำสายตาและลานโล่ง (Circulation First):** เว้นทางเดินหลักกว้างอย่างน้อย **4–6 เมตร** และลานรวมพล/จอดรถให้โล่งสะอาด (ไม่วาง prop ขวางทางเดินหรือจุดวาร์ป) ให้ผู้เล่น 50–100 คนวิ่ง/ยืน AFK ได้ไม่อึดอัด
4. **Zoning สีและวัสดุ (Material Contrast):** คู่สีสถาปัตย์ที่ดูแพงใน GTA V คือ **หิน/ปูนโทนสว่างอุ่น + ไม้จริง + เหล็กเข้ม/ทองเหลือง + พืชพรรณสีเขียวเข้ม/ดอกไม้ตัดสี** หลีกเลี่ยงสีนีออนสาดทั้งตึก ใช้สีแบรนด์เป็นจุดเน้น (ป้าย, แถบขอบ, แสงไฟ, โลโก้กลางลาน)
5. **ขอบล่างของ Sky Map (Sky Island Skirt):** แมพบนฟ้าต้องออกแบบขอบด้านข้างและใต้ฐานให้เรียบร้อย (แถบขอบสถาปัตย์, คานรองใต้ลาน หรือซับโครงสร้างสะอาด) ไม่ปล่อยให้เห็นหน้าโพลิกอนบางเฉียบหรือหน้ากลับด้าน (backface) เมื่อมองจากมุมต่ำ
